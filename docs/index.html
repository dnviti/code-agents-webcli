Features

Real terminals

Full pseudo-terminals over WebSocket with xterm.js — TUIs, colours, Ctrl-C, the lot. Not a chat box pretending to be a shell.

Eight agent CLIs

Whatever you already use. Each is optional; the app only runs what is on the host’s PATH, and plain shell sessions always work.

Multi-user isolation

GitHub OAuth with an explicit allow-list. Sessions are owner-scoped, so users only see and reconnect to their own work.

Scrollback that scales

The recent tail stays live; everything older is paged in from the server a screen at a time — and exports as Markdown.

Built for the phone

On-screen terminal keys, owned touch scrolling, a tab sheet, image attach, and an installable PWA.

Nothing to compile

No native dependencies: the terminal ships as a prebuilt binary and SQLite comes from Node itself. CI proves it on every commit.

Deploy

  • Requirements: Node 24.16 or newer, openssl on PATH, and a GitHub OAuth App. Nothing else.
  • HTTPS only: the server generates its own certificate authority on first start; trust it once per device from /ca.crt. A plain-http origin costs you the service worker, the clipboard and the installable app.
  • Background service: the setup wizard can install a systemd --user unit that starts at boot and survives logout.
  • Docker: ghcr.io/dnviti/code-agents-webcli ships the web server only — derive an image to add the agent CLIs, and mount a volume or your users and sessions vanish with the container.
  • Security: anyone on the allow-list gets a shell on the host as the user running the server. List only accounts you would give SSH to.
